# Client user guide

## 1. Run a search
**New Shipping Search** → enter origin and destination country (required), then whatever you know: weight, volume or piece dimensions, value, dates, scope (door-to-door etc.), customs/insurance needs. The **pre-search analysis** shows chargeable weights and lists any information still needed. Adjust the **ranking priorities** (price / speed / reliability) and click **Search best shipping prices**.

## 2. Read the results
- **Four recommendation cards**: Recommended, Cheapest, Fastest, Best value — each with price, transit, status, confidence, reasons, pros/cons and source.
- **Status badges** tell you how firm a price is:
  - *Verified Live Quotation* / *Manual Quotation* — firm prices you can book against (check validity).
  - *Indicative Online Price*, *Market Benchmark*, *Historical Price* — guidance only; request a quotation before deciding.
  - *Price Unavailable – Request Required* — the provider doesn't publish prices; use **Request quote**.
- **Like-for-like**: an offer is only comparable if it covers everything your scope needs. "Not like-for-like" lists the missing charges (e.g. customs, delivery).
- **Details** shows every charge line in its original currency and converted, with excluded/unknown items.
- **Sources searched** shows exactly which systems were checked and which were not (and why).

## 3. Get and enter quotations
**Request quote** opens a pre-filled RFQ (email or portal). When the reply arrives, click **Enter received quote** (or **＋ Manual quote**), enter each charge line and the source reference. The comparison and recommendations update immediately.

## 4. Decide
Use the currency selector, filters (method, status, provider, like-for-like, valid only) and sorting. **Landed cost** adds goods value, insurance, duty and VAT. **★ Save quotation** keeps a snapshot in Saved Quotations.

## 5. Reports & sharing
**Excel** and **PDF report** (opens a print-ready page — choose *Save as PDF*). **Share** creates a read-only link that expires; only send it to authorised recipients.

## 6. AI Freight Assistant
Ask in plain language: "Compare air and sea from Shanghai to Muscat for 500 kg, 2.4 cbm", then follow up: "fastest?", "alternatives to DHL", "explain #12 vs #15", "recheck prices", "landed cost". Open it from a search (**✦ Ask assistant**) to keep that search as context.
